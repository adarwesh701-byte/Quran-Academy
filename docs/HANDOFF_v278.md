## 2) طريقة الشغل
1. `git pull --ff-only` قبل أي حاجة.
2. **انشر قليل**: Vercel المجاني بيحسب نقل البيانات، فجمّع كذا بلوك في نشرة واحدة. آخر نشرة كانت v260–v263 مرة واحدة. تعديلات `docs/` لوحدها **ماتعملهاش push** إلا مع نشرة كود.
3. **الاختبار المحلي** (الطريقة الأساسية):
   - `tools/release/run.py` و`tools/release/stub.js` (Playwright + stub لـ supabase).
   - السكربت بيقرا `/home/claude/quran-academy/index.html` والبلوكات من `/home/claude/<اسم>.js`، فاعمل symlink للريبو هناك وانسخ البلوك لـ `/home/claude/`.
   - الأمر: `python3 tools/release/run.py "v1.js,v2.js" test.js [W H]`. ملف `test.js` فيه expression بيرجع object، والسكرين شوت بتتحفظ في `/home/claude/w/h/shot.png`.
   - دخول كطالب: `state.auth.user={id:'…'}; state.auth.profile={role:'student',…}`. والبيانات تتحط مباشرة في `state.data.<key>` (مثلًا `state.data.myAccess=[…]`).
4. **الاختبار على الموقع الحقيقي من غير نشر**: ارفع البلوك على فرع `devjs` (فرع orphan فيه `vercel.json` بيقفل النشر). بعدها في **متصفح Claude المدمج على جهاز المالك** افتح **تاب جديد** ونفّذ:
   `const r = await fetch('https://raw.githubusercontent.com/adarwesh701-byte/quran-academy/<SHA>/vNNN.js'); (0,eval)(await r.text()); render();`
   ⚠️ ماتحمّلش بلوك منشور أصلًا.
5. **النشر**، بالترتيب:
   1. حط البلوكات قبل آخر `// بدء التشغيل`.
   2. غيّر `const UI_VERSION = "2026-MM-DD-vNNN"`، و`itqan-vNNN` في `sw.js`.
   3. طلّع السكربت الأكبر وشغّل `node --check` عليه.
   4. شغّل `python3 tools/release/archive.py NNN "وصف"` (بيسيب آخر 3 نسخ بس).
   5. اعمل commit و`git -c push.negotiate=true push origin main`.
6. **كل تعديل يتسجّل في «🧩 النسخ والتعديلات»** (`const VER = () => [` جوه بلوك v254): ضيف سطر `["vNNN", اسم, [["vNNN.key", وصف]]]`، ولفّ الكود بـ `FF("vNNN.key")`، والدالة: `const FF = k => { try { return window.ff254(k); } catch (e) { return true; } };`.
7. **نمط التعديل**: غلّف الدالة اللي موجودة (`const _r = render; render = function(){ const o=_r.apply(this,arguments); …; return o; }`) وماتكتبش فوقها. الدوال اللي بتتعرّف بـ `function x` في السكربت الرئيسي global وينفع تتبدّل.
8. **ممنوع** تسجّل دخول على الموقع الحقيقي بكلمة سر.
9. الـ commit بيخلص بسطور الـ attribution بتاعة الجلسة لو موجودة.

- **v208** بيحوّل كلام الواجهة للفصحى بـ MutationObserver، وبيعدّي أي حاجة جوه `[lang]` أو `.notr`. عشان كده v259 بيحط `lang="ar-EG"` على صفحة العامية. أي محتوى عامية جديد لازم يتعامل بنفس الطريقة.

## 3) قواعد المالك الثابتة
- الكلام مصري + «📌 المطلوب منك» في آخر كل رد.
- **ماتمسحش الموجود**، زوّد عليه. (استثناء: النسخ المحفوظة آخر 3 بس.)
- أي ميزة جديدة: يا إما في «🆕 كل الجديد» مقفولة، أو بزرار تشغيل للمالك، أو تتقفل من «النسخ والتعديلات».
- الترتيب: القرآن ← التجويد ← المقامات ← الباقي.
- **القرآن عمره ما يتقري بالذكاء الاصطناعي**. صوت الكلمة من الشيخ نفسه (quran.com word-by-word: `wbwPlay`/`wbwUrl`). Azure للعربي بس.
- مفيش مصادر مكتوبة على المحتوى (لا مايكروسوفت ولا أسماء كتب).
- الأذان والأناشيد والابتهالات والأشعار **مابتتترجمش**: فرانكو جنب كل سطر + «عرض الترجمة».
- وسائل الدفع الظاهرة: InstaPay وVodafone Cash وPayPal. **مابنخزّنش أرقام كروت.**
- **مفيش لينكات خارجية للمحتوى خالص** (لا يوجد ولا غيره). يا الملف نفسه على الموقع، يا يتشال. (N4)
- `userEmail` مايتعرضش. صور الـ AI بعد موافقة المالك. مفيش تسجيل صوت للحصص (تفريغ بس).
- **العربي**:
  - الفرانكو مع العربي مش مع الإنجليزي، والعربي RTL.
  - في الاختيارات واحد بس صح، والاختيارات عشوائية.
  - قبول واسع للإجابات المفتوحة.
  - ترتيب الوحدة: الحوار (قراءة ← سماع ← تفاعل) ← الكلمات والأدوات والألعاب ← القاعدة ← امتحان الوحدة.
  - «خلصت» بعد 70% بس.
  - الفتح مستوى مستوى، واختبار تحديد بيفتح اللي قبل المستوى، والمالك أو المعلم يفتح لأي طالب.
- **العامية بالعامية** (مش فصحى)، والفصحى بالفصحى.
- **أي سؤال (عامية/فصحى/أطفال)**: السؤال بالعربي (ومعاه فرانكو لو المستوى بيحتاج)، والإجابات عربي وجنبها الإنجليزي.

   - ≥70% ← يعدّي للمستوى اللي بعده · <50% ← يبدأ من المستوى ده · 50–70% ← يعيد المستوى بأسئلة **تانية مختلفة**.
   - بعد ما يخلص: يفتح كل اللي قبل مستواه (زي `ka_place258`).
   - المكان: لفّ `lvStart`/`LVQ` في v116، أو صفحة جديدة بنفس الـ route `level`.
2. **أسئلة العامية في `LVQ.egyptian`**:
   - كل سؤال عربي + فرانكو، والإجابات عربي وجنبها الإنجليزي (زي صورة «تسلم إيدك»).
   - **اختيار واحد بس صح** — صلّح «اللي اختشوا ماتوا» و«خليها على الله» و«عقبالك» (كان فيها «As-Salām — The Source of Peace» غلط).
   - «العزا» لازم تتكتب عربي مش فرانكو بس.
   - نفس الشغل لـ `LVQ.fusha` وباقي الأقسام.
3. **شيل كل اللينكات الخارجية للأناشيد والمحتوى** (يوتيوب وغيره) من الأناشيد وكل صفحات المقامات (أساسية وفرعية)، ومن أي مكان في المنصة. اللي ملفه مش على الموقع يتشال.
4. **صور المصاحف** (شمرلي، المدينة، …) من مصدر عام نشره مسموح (مثلًا صفحات مصحف المدينة من مجمع الملك فهد/Quran.com/Tanzil). بعدها: اختيار المصحف + الأحكام والروايات عليه + «المقارنة مع حفص» صفحة صفحة والخلافات في الهامش ملوّنة.
5. **كل المشايخ لكل رواية**: من mp3quran API (`MP3Q.list`) لكل رواية متاحة (رجّع عبد الرشيد صوفي) + اختيار القارئ المتاح بس.
6. **الشريط اللي فوق**:
   - ثابت دايمًا (default)، و«يطلع وينزل» اختيار في الإعدادات (`top261.mode`). فيه كود قديم لسه بيحرّك الهيدر — دوّر عليه وعطّله لما `mode=fixed`.
   - صف واحد: «🧰 الأدوات» و«🎁 احصل على اشتراك مجاني» و«🗺️ دليل الموقع» (الشريط التاني `.dombar`) يطلعوا في نفس صف «الرئيسية».
   - أيقونة جنب كل اسم (الرئيسية 🏠، دورات الأكاديمية 🎓، من نحن والتواصل ℹ️ …).
   - الأيقونة 👨‍🏫 اللي من غير كلام تبقى «👨‍🏫 مع معلمي» للطالب/المشترك و«👨‍🏫 مع طالبي» للمعلم.
   - شيل 🕌 اللي جنب اللغة (`#hbi168`).
   - الحجم حسب الشاشة: في الصغيرة كله ظاهر في العرض بحجم أصغر، وفي الكبيرة حجم مناسب.
   - المالك يرتّب من ✏️ (موجود).
7. باقات العيلة جوه «اشترك» زي باقي الأقسام (N3 #33).
