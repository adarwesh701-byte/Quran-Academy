## 1) طريقة الشغل
1. `git pull --ff-only` قبل أي حاجة.
2. كل تعديل = بلوك جديد `vNNN.js` شكله:
   `/* ================= vNNN: وصف بالمصري ================= */ (function(){ … })();`
   النسخة الجاية: **v249**.
3. النشر: `tools/release/rel.sh NNN "رسالة"` (موجود في الحزمة تحت `scripts/`؛ غيّر المسارات `/home/claude/...` لمكانك). بيحط البلوك قبل آخر `// بدء التشغيل`، ويغيّر `UI_VERSION` و`sw.js`، ويعمل `node --check`، ويحفظ في `archive/` (آخر 10)، ويعمل commit وpush. Vercel بينشر لوحده في دقيقة.
4. نمط التعديل: غلّف الدوال ماتكتبش فوقها: `const _r = render; render = function(){ const o=_r.apply(this,arguments); … ; return o; }`.
5. **الاختبار:**
   - محلي: `scripts/harness/run.py` (Playwright + `stub.js` بدل supabase). مثال: `python3 run.py t.html script.py 390 844`. بيكتشف أخطاء JS والتخطيط، بس **مافيهوش داتا المكتبة**.
   - **على الموقع الحقيقي (الأهم):** من متصفح Claude المدمج على جهاز المالك (هو مسجّل دخول كمالك). اعمل inject للبلوك بـ `javascript_tool` في الصفحة، جرّب، وبعدين انشر. صفحات المكتبة/المقامات/المصحف بتتبني من DB ومش بتبان غير كده.
   - ممنوع تسجّل دخول بكلمة سر.
6. بعد النشر: استنى ~60 ثانية، reload، واتأكد `UI_VERSION` = النسخة الجديدة.

## 5) Vercel — «المساحة خلصت»
- **مانقدرتش نشوف صفحة الاستخدام:** متصفح Claude مش مسجّل دخول على Vercel. المالك يدخل بنفسه في المتصفح المدمج (vercel.com) وبعدين الأداة تقرا `https://vercel.com/dashboard/usage`.
- **حجم كل نشرة ~64 ميجا**: `archive/` = 51 ميجا (10 نسخ كاملة من الموقع، كل واحدة ~5 ميجا — بيستخدمها «نسخ الموقع» في الإعدادات: `/archive/vNNN.html`)، `index.html` 5.1 ميجا، `qr/` 4.8 ميجا (القراءات)، `fqs.json` 1.3 ميجا. ملفات النشر نفسها مش بتتحسب من حدود Hobby غالبًا؛ اللي بيتحسب: **Fast Data Transfer (100 GB/شهر)، Fast Origin Transfer (10 GB)، Edge Requests (1M)، Build minutes**.
- **السبب المرجّح للاستهلاك:** كل نشرة بتغيّر `UI_VERSION` → كل زائر بينزّل `index.html` (5 ميجا) من الأول. 19 نشرة في يوم واحد × عدد الزوار = نقل بيانات كبير. **الحل:** تجميع التعديلات في نشرات أقل (مثلًا نشرة واحدة آخر اليوم)، وعلى المدى الأطول تقسيم `index.html` لملفات lazy.
- لو الحد اللي خلص Bandwidth/Requests: على Hobby الخدمة بتقف لحد ما تعدّي 30 يوم. **Hobby ممنوع للاستخدام التجاري** (الأكاديمية تجارية) → المطلوب **Pro: ‏20$ شهريًا لكل عضو** (فيه 20$ رصيد استخدام، و1 TB نقل، و10M طلب). الاشتراك شهري. من Vercel ← Settings ← Billing ← Upgrade (المالك يدفع بنفسه).
- **ماتمسحش `archive/` من غير ما المالك يوافق** (قاعدة «آخر 10 نسخ»). اختيار وسط: تقليلها لآخر 3 أو نقلها لـ GitHub Releases.

## 7) اللي لسه (بالترتيب)
1. **التجويد — صوت الكلمات:** أي مكان بيقول كلمة قرآن بصوت كمبيوتر (اختبارات التجويد، بطاقات المراجعة `fc223`، رحلة التجويد، أمثلة الأحكام) → `wbwPlay` بموقع الكلمة. ولأحكام النون والميم واللام: الكلمتين ورا بعض. أمثلة كل حكم تحته بالصوت (صور 36، 211314، 47).
2. **اختبار التجويد:** شرح بعد كل إجابة، تكرار الغلط، التحكم في التايمر، الأحكام بنفس طريقة الكتابة (صور 37–38).
3. **القراءات:** اختيار القارئ المتاح للرواية بس (صورة 31)؛ زرار «ابعت للمعلم» على التسجيل كواجب (صورة 30).
4. **المخارج:** سهم الهمس والجهر، درجات فتح مختلفة لنفس المخرج، حروف الحلق مايتحركش فيها اللسان، صور/حركة واقعية (صورة الضاد)، التفخيم والترقيق تحت الصفات.
5. **العربي:** الترجمة مخفية وتتفتح كلمة كلمة؛ محادثات أطول وأكتر (B يستنى تسجيل الطالب وتوقيت طبيعي)؛ تسجيل صوت الطالب؛ «خلصت» + شهادة؛ اختيار الطالب؛ شيل المكرر والفاضي؛ فلاش كارد بالفرانكو + صعوبة Anki + كروت قواعد؛ الترتيب: الحوار ← القواعد ← الكلمات ← الفلاش كارد (صورة 210923).
6. **الشرايط الجانبية:** نفس التصميم، اختيار مكانها، شريط الإعدادات مخفي ويطلع بزرار (صورة 3)، رجوع زرار اللغة والعرض على الجنب (041529).
7. **وضع البناء زي فولدرات الكمبيوتر:** نقل، حذف لسلة، تحديد متعدد، تطبيق «عليّ» أو «للكل»، تعديل النص، تطبيق على الصفحات الشبيهة، كليك يمين، معاينة قبل الحفظ.
8. **صفحة القرّاء للمالك:** كل المشايخ + بحث عربي/إنجليزي، تقطيع الآيات (أوتوماتيك) ورفعها في مقام الشيخ، إظهار الشيخ بعد الرفع بس، «إبلاغ عن خطأ».
9. **باقي:** أكتر من جواب للمقام؛ النص تحت الأذان/الابتهال بزرار «عرض»؛ كلمات الأناشيد؛ علامة الصوت على الكتب واختيار طريقة العرض؛ الأذان في الخلفية؛ أيقونات التنقل (الرئيسية · مساحتي · دورات · المحتوى)؛ رجوع لوقت معيّن في النسخ الاحتياطية؛ التطبيق: «التعرّف على الصوت محتاج إنترنت»؛ نطق «ربك».
10. **الاقتراحات الباقية (~30):** شوف تقرير Docs قسم الاقتراحات.
