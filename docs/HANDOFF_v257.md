## 2) طريقة الشغل (مهم)
1. `git pull --ff-only` قبل أي حاجة.
2. **انشر قليل**: Vercel المجاني بيحسب نقل البيانات — جمّع كذا بلوك في نشرة واحدة (آخر نشرة كانت v254–v257 مرة واحدة).
3. **اختبار على الموقع الحقيقي من غير نشر** (أسرع طريقة): ارفع البلوك على فرع `devjs` (فرع orphan فيه `vercel.json` بيقفل النشر):
   ```bash
   # مرة واحدة: git clone --branch devjs … /home/claude/devjs   (أو اعمله orphan جديد)
   cp vNNN.js /home/claude/devjs/ && cd /home/claude/devjs && git add -A && git commit -m dev && git push -f origin devjs && git rev-parse HEAD
   ```
   وبعدين في **متصفح Claude المدمج على جهاز المالك** (هو داخل كمالك) — افتح **تاب جديد** (المالك بيستخدم التاب الأساسي):
   ```js
   const r = await fetch(`https://raw.githubusercontent.com/adarwesh701-byte/quran-academy/<SHA>/vNNN.js`); (0,eval)(await r.text()); render();
   ```
   ⚠️ ماتحمّلش بلوك منشور أصلًا تاني (هيتلف مرتين). ولو عايز تحمّل نسخة جديدة اعمل `location.reload()` الأول (`navigate` للـ hash مش بيعمل reload).
4. **اختبار محلي**: `tools/release/run.py` + `tools/release/stub.js` (Playwright + stub لـ supabase):
   `python3 tools/release/run.py "v1.js,v2.js" test.js` — `test.js` فيه expression بيرجع object. لدخول كطالب: `state.auth.user={id:'…'}; state.auth.profile={role:'student',…}`.
5. **النشر**: حط البلوكات قبل آخر `// بدء التشغيل` ← غيّر `const UI_VERSION = "2026-MM-DD-vNNN"` و`itqan-vNNN` في `sw.js` ← طلّع السكربت الرئيسي واعمل `node --check` ← `python3 tools/release/archive.py NNN "وصف"` (**بيسيب آخر 3 نسخ بس** — طلب المالك) ← commit/push. اختبر بعد النشر إن `UI_VERSION` اتغيّر.
6. **كل تعديل جديد يتسجّل في «🧩 النسخ والتعديلات»** (`VER()` جوه v254): اكتب مفاتيح التعديلات، ولف كل تعديل بـ `FF("vNNN.key")` (الدالة: `const FF = k => { try { return window.ff254(k); } catch (e) { return true; } };`). كده المالك يقفل أي تعديل لوحده.
7. نمط التعديل: غلّف الدوال الموجودة (`const _r = render; render = function(){ const o=_r.apply(this,arguments); …; return o; }`) وماتكتبش فوقها.
8. **ممنوع** تسجّل دخول على الموقع الحقيقي بكلمة سر. المتصفح المدمج عند المالك داخل أصلًا.

## 6) أكبر البنود اللي لسه (تفاصيل)
### 6-أ) قسم «الأدوات» الجديد (Notion 3 — النص في `docs/notion3/NOTION3_TEXT.txt` من «شيل باقات الاشتراك…» لـ «ادخل على القسم دا عندي اتحكم في كل حاجة»)
- «مساحتي» تبقى للمالك بس (أفكاره الجديدة وزرار «ارفعها للأدوات»). الطالب ماعندوش «مساحتي».
- «الأدوات» بشكل عرض «مساحتي» (مش شكل الأدوات الحالي)، وفيها **بالترتيب ده تقريبًا**: تعلّم المقامات الصوتية «للقرآن والإنشاد» (أول حاجة — مدفوع) · القراءات العشر (مفتوحة كاملة، فوق) · الأذكار (فوق) · اسمع من غير مصحف · منهج العلوم الشرعية (فيه قسم العلوم الإسلامية كامل) · النحو والصرف والبلاغة من الصفر للقمة (فيه قسم النحو والصرف والبلاغة) · المصحف الملوّن (يدخل على صفحة المصحف علطول) · مخارج الحروف وصفاتها · تحفة الأطفال والجزرية · خطط حفظ ذكية · استمع للقرآن مع فيديو · قصص الأنبياء والسيرة · تكلّم عربي (كل أقسام العربي — مدفوع — بعد المقامات علطول) · قصص مصوّرة · ختمة العيلة · الأربعون النووية · أسماء الله الحسنى · «اعمل كارت آية وشاركه» · مواقيت الصلاة · اعرف مستواك (راجع أسئلته كويس) · أعلام الإسلام · خمّن المقام (مدفوع) · الوايت بورد (مجانية للكل) · الباقي يتشال.
- اللي يتشال من الأدوات: باقة العيلة، كل شيء تطلّه، شكل الموقع، القواعد، شكل الشرايط الجانبية، اهتماماتي، اشترك في قسم، ارجع شريط التطبيقات، شكل الفم. «مع معلمي» و«رحلتي وإنجازاتي» و«ملفي ومتابعتي» و«الواجبات» و«شهادتي» و«التسميع» ← «رحلتي مع معلمي». «الكتب التفاعلية» و«الكتب المصوّرة»: المالك يرفع فيها.
- الزوار: يشوفوا الأدوات، ولما يدخلوا على حاجة تظهر «سجّل الأول» (بـ X تقفلها وتكمّل)، وبتظهر كل شوية. المدفوع: «محتوى مدفوع — اشترك في محتوى المنصة» + لينك الاشتراك.
- **تحكم المالك الكامل**: إنشاء قسم، اختيار اللي جواه من الأدوات ومن مساحته، طرق عرض كتير مع معاينة، النقل بين الأقسام، الترتيب، الاسم والأيقونة، ولكل أداة: مفتوحة / «سجّل الأول» / «مدفوع — اشترك».
- اقتراح للتنفيذ: إعداد `site_settings.tools258 = {groups:[{name,icon,view,items:[{js,access:'open'|'login'|'paid'}]}]}` + صفحة عرض + محرر بمعاينة (ابدأ من كود `life249` في v249 — نفس الفكرة).
### 6-ب) «لوحة التحكم» = الملف + الإعدادات (Notion 3)
شريط جانبي (يمين بالعربي/شمال بالإنجليزي): الاسم الظاهر، اللغة، الدولة، وسائل الدفع (مع حفظ الكارت من بوابة الدفع — **مش** إن احنا نخزّن أرقام كروت)، الخط وحجمه، شكل الموقع، الحجوزات، الإشعارات… كل جزء بيتفتح «زي ورقة بتتفرد». للكل (طالب/معلم/مالك)، والمالك يتحكم في اللي يظهر للطلاب والمعلمين ويضيف خانات. الموقع يلقط المكان لمواقيت الصلاة والجداول.
### 6-ج) «رحلتي مع معلمي» (طالب) / «مع طلابي» (معلم)
الجداول، الحصص، الفصول، الوايت بورد، الواجبات، الشهادات، التسميع، رحلتي وإنجازاتي، ملفي ومتابعتي، ملفات الطلاب للمعلم — كل حاجة بين المعلم والطالب.
### 6-د) الشريط اللي فوق
شريط لوحتي (مساحتي/حصصي/ملفي) يطلع فوق جنب «الرئيسية». المالك: يرتّب، يغيّر الأسماء، ينقل، يضيف أيقونة، ويختار يفضل ظاهر أو يختفي.
### 6-هـ) الفتح بالتايمر
«افتح محتوى»: وحدة (دقايق…مدى الحياة) + عدد. الوقت **يبدأ لما الطالب يضغط «تفعيل»**. تايمر تنازلي في مكان مناسب، والمالك يغيّر مكانه. نفس الفكرة للساعة المجانية كل شهر. محتاج: عمود `starts_on_activate` في `content_access` + RPC للتفعيل + تعديل `owner_grant_access/owner_grant_section`.
### 6-و) المصاحف والقراءات
- اختيار المصحف (الشمرلي، المدينة، أشهر المصاحف) والأحكام والروايات على المصحف المختار. ⚠️ محتاج صور صفحات بحقوق استخدام. اقتراح: مجمع الملك فهد/Quran.com APIs للخط والصفحات.
- كل المشايخ لكل رواية (رجّع عبد الرشيد صوفي).
- «مصحف المقارنة مع حفص»: السورة كاملة أو صفحة صفحة، والخلافات في الهامش وملوّنة. شيل «مصحف الروايات نص وصوت».
- القراءات العشر قسم واحد في الشريط.
### 6-ز) المقامات
- الدرجات: B2/C4 جنب Re/Mi/Fa.
- مدى الصوت: مسافات بالنسبة (التون = ضعف النص تون)، وزرار أوكتاف فوق/تحت، والزراير بالعرض.
- الصوت مش متزامن مع صوت الطالب (image 4).
- الكاريوكي يتنقل لـ«أنشد معي»، والابتهال يبقى للصوتيات زي المرتل.
### 6-ح) «العب دور» في الحوار
لما الموقع يخلّص سطره يبدأ يسمع لوحده. يستنى الطالب يخلّص (v250 بيستنى السكوت)، وبعدين يكمّل.
### 6-ط) العربي (**بعد موافقة المالك بس**) — الخطة كاملة آخر `ITQAN_STATUS_ALL.md`
الملفات اللي وصلت (في uploads بتاعة المحادثة — **لازم تتطلب تاني لو انت في محادثة جديدة**):
- «العربية بين يدي أولادنا» 1→9 (صور ممسوحة).
- الصرف التعليمي (424 ص)، النحو التعليمي (1088 ص)، البلاغة الميسرة (100 ص)، أسرار البلاغة (326 ص).
- أنستونا (176 ص)، كلّمني عربي بشويش (132 ص)، قواعد العامية بالإنجليزي (225 ص — فيها نص).
- «العربية بين يديك»: [Drive](https://drive.google.com/drive/folders/13nu_XdKbqM_RDpOOi6xUAkDABP3LkzCo?usp=drive_link).
- أدوات: `tesseract` فيه `ara`. الكتب الممسوحة مفيهاش طبقة نص.
- بيانات الفصحى الحالية: `fuD()`، والوحدة `[title, icon, words[[ar,fr,en]], lines[[who,ar,fr,en]], grammar…]`. الأطفال: `KA` (`go16('kidsar')`).

## 7) اللي لسه بالترتيب (اقتراح)

## 8) أفكار ماركتنج (اتعمل منها: المسابقة، الفيديو، صورة أول 10، كود الخصم)
- **مسابقة الأسبوع** (موجودة): انشر الأول من كل قسم يوم الجمعة على فيسبوك/إنستجرام/تيك توك بالفيديو الجاهز (زرار 🎬)، ومنشن الطالب.
- **«سورة الأسبوع من غير مصحف»** كتحدّي ثابت كل جمعة + هاشتاج ثابت للأكاديمية.
- **كود خصم شخصي لكل فايز** (الكود يظهر على الفيديو) — كل اشتراك بالكود يدّيله نقط أو أيام مجانية (موجود «ادعي أصحابك»؛ اربطه بالمسابقة).
- **لايف شهري** لأوائل الشهر مع المعلمين، والتسجيل يترفع في محتوى الطلاب.
- **«قبل وبعد»**: تسجيل الطالب أول يوم وبعد 3 شهور (بإذنه) — أقوى إعلان.
- **شهادات قابلة للمشاركة** بصورة فيها اللوجو واللينك (موجودة جزئيًا: شهادة الجزء).
- **صفحات SEO** لكل مقام وكل حكم تجويد (بند ⬜ في الاقتراحات) — بتجيب زوار من جوجل.
- **واتساب**: رسالة أسبوعية للمشتركين بالفايزين + سورة الأسبوع (يحتاج WhatsApp Business API).
- **برنامج سفراء**: المعلمين والطلاب المميزين ياخدوا نسبة من الاشتراكات اللي جت عن طريقهم.
